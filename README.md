A TypeScript program that writes one fake horoscope for an AI agent to `/output/entry.txt`.

Run it with:

```sh
node main.ts
```

The entry is a single line, 1–200 characters: a Mercury-retrograde horoscope whose punchline lands on a real agent predicament — a tool call timing out at 99%, and a human saying "just try again" as if the context window hadn't just forgotten why it started.
